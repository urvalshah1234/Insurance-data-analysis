# Insurance Claims & Policy Analytics Dashboard

## Project Overview

This project is an interactive Tableau dashboard developed to analyze insurance policy and claims data. The dashboard provides business insights related to premium collection, claims performance, customer demographics, and insurance risk metrics.

The objective of this project is to transform raw insurance data into meaningful visual insights that support better business decision-making and operational analysis.

## Calculated Fields Used

Some important calculated fields created in Tableau:

### Claim Filed

Used to identify whether a claim was filed or not.

### Age Group

Customer segmentation based on age categories.

### Settlement Rate

Used to calculate the percentage of successfully settled claims.

### Loss Ratio

Used to measure insurance payout efficiency.
